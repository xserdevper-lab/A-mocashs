# A-mocashs

แอปรายรับรายจ่ายภาษาไทย รองรับมือถือและคอมพิวเตอร์ ออกแบบโทนฟ้าและโหมดสว่าง/มืดจากภาพอ้างอิง

## เปิดใช้งาน

[ติดตั้ง A-mocashs จาก GitHub Pages](https://xserdevper-lab.github.io/A-mocashs/)

- Android / Chrome / Edge: เปิดลิงก์แล้วกด **ติดตั้งแอป** หรือใช้เมนูติดตั้งของเบราว์เซอร์
- iPhone / iPad: เปิดด้วย Safari → แชร์ → **เพิ่มไปยังหน้าจอโฮม**
- Mac / Safari: ไฟล์ → **เพิ่มไปยัง Dock**

UI ทุกหน้าทำงานจาก HTML/CSS/JavaScript บน GitHub Pages โดยตรง Google Apps Script เป็น backend รับส่งข้อมูลกับ Google Sheet เท่านั้น iframe ที่ซ่อนทำหน้าที่ส่งคำสั่ง ไม่มี UI ของแอปอยู่บน Google

## เข้าสู่ระบบและเลือกพื้นที่

- เข้าแอปแล้วกด **เข้าสู่ระบบด้วย Google** ใช้ได้เฉพาะอีเมลสองบัญชีที่ตั้งไว้ฝั่งเซิร์ฟเวอร์
- **ส่วนรวม**: ทั้งสองคนอ่าน/บันทึกบัญชี รายการ และหนี้ร่วมกัน ข้อมูลเดิมทั้งหมดอยู่ในพื้นที่นี้
- **ส่วนตัว**: บัญชี รายการ และหนี้แยกตามผู้ใช้ เซิร์ฟเวอร์เลือกพื้นที่จากตัวตนที่ Google ยืนยัน ผู้ใช้ระบุ ID ของอีกคนเพื่อขอข้อมูลไม่ได้
- กด **ออกจากระบบ** ก่อนเปลี่ยนผู้ใช้หรือคืนอุปกรณ์ เซสชันหมดอายุไม่เกิน 6 ชั่วโมง และต้องเข้าสู่ระบบใหม่เมื่อโหลดหน้าใหม่
- การสำรอง JSON/CSV ใช้เฉพาะข้อมูลในพื้นที่ที่เลือก

GitHub Pages และ service worker เก็บเฉพาะ UI สาธารณะ ไม่เก็บข้อมูลการเงินหรือข้อมูลเข้าสู่ระบบ ข้อมูลจริงอยู่ในหน่วยความจำของหน้าและ Google Sheet ซึ่งตั้งการแชร์เป็น **จำกัด** ไม่ต้องแชร์ชีตให้ผู้ใช้อีกคน

การแยกส่วนตัวเป็นสิทธิ์ภายในแอป เจ้าของ Google Sheet/ผู้ดูแล Apps Script ยังมีสิทธิ์ดูข้อมูลดิบทุกพื้นที่ในฐานข้อมูล

## ภาษา

หน้าการตั้งค่ามีตัวเลือกภาษาไทย อังกฤษ เกาหลี และญี่ปุ่น ภาษาที่เลือกถูกบันทึกไว้ในเบราว์เซอร์ วันที่และข้อความ UI เปลี่ยนตามภาษา ชื่อบัญชีและรายละเอียดที่ผู้ใช้บันทึกไว้คงเดิม

## ฟังก์ชัน

- เพิ่มบัญชีพร้อมยอดเริ่มต้น แสดงยอดเงินคงเหลือทุกบัญชีและยอดรวม
- บันทึกรายรับ รายจ่าย และโอนระหว่างบัญชี รายจ่ายหักยอดทันทีและป้องกันยอดติดลบ
- กรองรายการตามเดือน บัญชี ประเภท และค้นหาชื่อรายการ
- เพิ่มหนี้ประจำเดือน พร้อมวันครบกำหนด และสถานะรอชำระ/เกินกำหนด/ชำระแล้ว
- บันทึกชำระหนี้เป็นรายจ่ายจากบัญชีที่เลือก ป้องกันชำระซ้ำ สถานะแยกเดือน
- เครื่องคิดเลขรองรับวงเล็บและลำดับการคำนวณ นำยอดไปบันทึกต่อได้
- ส่งออก CSV และสำรองข้อมูล JSON

## ใช้งานกับ Google Sheet

ฐานข้อมูล: https://docs.google.com/spreadsheets/d/16cELFn6q08ITvp8uT-3PKHfsAf-R7wIMNH6t6DgTd5U/edit

1. เปิด Google Sheet → ส่วนขยาย → Apps Script แล้ววาง `google-apps-script/Code.gs`
2. สร้าง OAuth Client ประเภท Web application ใน Google Auth Platform โดยกำหนด Authorized JavaScript origin เป็น `https://xserdevper-lab.github.io` Authorized redirect URI เป็น `https://xserdevper-lab.github.io/A-mocashs/` ตัว Client ID เป็นข้อมูลสาธารณะ ไม่ต้องใส่ Client Secret ใน UI
3. ตั้ง Script Properties `GOOGLE_CLIENT_ID` เป็น Client ID และ `MEMBER_EMAILS` เป็น JSON array ของอีเมลสองคน (เจ้าของเป็นรายการแรก) เก็บค่าจริงใน Script Properties เท่านั้น ไม่ commit อีเมลส่วนตัวลง GitHub
4. Deploy เป็น Web app → execute as **ฉัน** → access **ทุกคน** ตัวช่องทางรับส่งเข้าถึงได้ แต่ทุกการอ่าน/เขียนต้องมีเซสชันที่ตรวจสอบแล้ว อย่าเปิด access ทุกคนกับ backend รุ่นเก่าที่ไม่มี `src/auth.gs`
5. เจ้าของอนุญาต scope ของ Spreadsheet และการเรียก HTTPS ภายนอกเพื่อยืนยัน Google Token แอปขอจากผู้ใช้เพียง `openid email profile` ไม่ขอรหัสผ่าน Google หรือสิทธิ์อ่าน Google Drive ของแฟน
6. ใช้ URL deployment นี้ใน `src/bridge-client.js` แล้ว build/publish `docs/` ตั้ง Sheet sharing เป็น **จำกัด** ต่อไป

ระบบยืนยัน Google Access Token กับ token-info และ userinfo ของ Google ผ่าน HTTPS ตรวจ client audience, token expiry, verified email และรายชื่อสมาชิก พร้อมผูก Google subject ID ป้องกันการสลับตัวตน รายชื่อสมาชิกไม่ถูกส่งไป UI หน้า Google เปิดโดยตรงแล้วกลับมาที่ GitHub โดยตรวจ OAuth state แบบใช้ครั้งเดียวและลบ token จาก URL ทันที ข้อมูลใน sessionStorage มีเฉพาะคำขอตรวจ CSRF ไม่เก็บ token หรือข้อมูลการเงิน เซสชันเป็น token สุ่ม เก็บ hash ฝั่งเซิร์ฟเวอร์และยกเลิกเมื่อออกจากระบบ

Log ของส่วนรวมใช้ `Amocashs_Log` เดิม ไม่มีการย้ายหรือล้างข้อมูล ส่วนตัวใช้ `Private_<user-id>_Log` แต่ละพื้นที่มีตาราง Accounts, Transactions, Debts และ Payments เป็น projection ของ log อย่าแก้ไขตารางโดยตรง เรียก `rebuildViews_` ใน editor เพื่อสร้างตารางส่วนรวมใหม่ได้

ป้องกันการเขียนทับจากหลายอุปกรณ์ด้วย script lock, revision และ request ID เมื่อข้อมูลเปลี่ยนจากอีกอุปกรณ์ แอปจะโหลดข้อมูลล่าสุดและขอให้บันทึกใหม่ ระบบยังไม่มีการแก้ไข/ลบรายการย้อนหลัง ควรตรวจข้อมูลก่อนบันทึก

## ตัวอย่างเว็บแบบออฟไลน์

เปิด `dist/index.html` ผ่าน HTTP server หรือไซต์ตัวอย่าง ข้อมูลของโหมดนี้เก็บใน localStorage ของเบราว์เซอร์และไม่ซิงก์เข้า Google Sheet อัตโนมัติ หน้า Settings สามารถโหลดข้อมูลตัวอย่างได้เมื่อไม่มีข้อมูลเดิม ข้อมูลตัวอย่างมีป้ายกำกับชัดเจน

## พัฒนาและทดสอบ

ต้องมี Node.js 18 ขึ้นไป build และทดสอบจาก vendor bundle ได้โดยไม่ต้องติดตั้ง dependency; หากแก้ crypto bundle ให้ `npm install` แล้ว `npm run build:crypto`

```sh
npm test
npm run build
python3 -m http.server 4173 --directory dist
```

แก้ไขไฟล์ `src/` แล้ว build เพื่อสร้าง `dist/` และไฟล์ Apps Script ที่พร้อมติดตั้ง เมื่ออัปเดต Apps Script ให้สร้างเวอร์ชันใหม่ใน Manage deployments เพื่อให้ URL เดิมใช้เวอร์ชันใหม่

UI หลักอยู่ใน `src/` และ PWA manifest/icons/service worker อยู่ใน `pwa/` เมื่อ build จะรวมเป็น `docs/` สำหรับ GitHub Pages ตั้งค่า Pages → Deploy from a branch → main → /docs เมื่อแก้ไฟล์ PWA ให้ build และ commit `docs/` ด้วย

ช่องทางข้อมูล Google `?bridge=1` ตรวจ origin, หน้าต่าง, nonce และ client challenge ก่อนรับข้อความ ทุก endpoint อ่าน/เขียนตรวจเซสชันและ scope ฝั่งเซิร์ฟเวอร์ ฟังก์ชันภายในลงท้าย `_` เพื่อป้องกันการเรียกผ่าน `google.script.run` โดยตรง

## ข้อจำกัด

- เป็นแอปบันทึกการเงิน ไม่เชื่อมธนาคารหรือโอนเงินจริง
- หนี้เป็นยอดคงที่ต่อเดือน ไม่มีการคำนวณดอกเบี้ย/ตัดเงินต้น
- Snapshot จำกัดประมาณ 2 ล้านตัวอักษร และจำนวนการเรียกใช้อยู่ภายใต้โควตา Google Apps Script/Google Sheets
- ข้อมูลแบบออฟไลน์อาจหายเมื่อเคลียร์ข้อมูลเบราว์เซอร์ ควรดาวน์โหลดสำรองข้อมูล
- CSV ส่งออกเฉพาะรายการตามตัวกรองที่เลือก JSON สำรองทุกบัญชีในพื้นที่ที่เลือก

## ปลดล็อกด้วยเครื่องนี้ (Passkey)

เข้า Google ครั้งแรก → การตั้งค่า → ตั้งชื่อเครื่อง → ลงทะเบียนเครื่องนี้ → ยืนยันผ่าน PIN/Face ID/ลายนิ้วมือในหน้าต่างของระบบ ครั้งต่อไปใช้ปุ่ม “ปลดล็อกด้วยเครื่องนี้” ที่หน้าล็อกอินได้ ไม่ต้องส่งหรือเก็บ PIN เครื่องไว้ในแอป หากไม่รองรับหรือไม่พบ Passkey ยังใช้ Google Login ได้

Passkey ผูกกับบัญชีที่ Google ยืนยันไว้ ไม่เปลี่ยนบัญชีส่วนตัวหรือข้อมูลส่วนรวม กุญแจสาธารณะและข้อมูลลงทะเบียนเก็บใน Script Properties; private key อยู่ใน authenticator/ผู้จัดการ Passkey ของเครื่อง ผู้ให้บริการอาจซิงก์ Passkey ไปยังอุปกรณ์ของเจ้าของบัญชีได้ ถอนสิทธิ์เฉพาะรายการของตัวเองได้ใน Settings ซึ่งยกเลิกเซสชันที่ออกจาก Passkey นั้นด้วย การถอนสิทธิ์ในแอปไม่ได้ลบรายการจากผู้จัดการ Passkey ของเครื่อง

WebAuthn ใช้ RP ID `xserdevper-lab.github.io` และตรวจ origin เดียวกัน มี challenge แบบใช้ครั้งเดียวหมดอายุ 5 นาที บังคับ user verification และ resident key ตรวจ RP hash, user handle, ลายเซ็น ES256 และ sign counter แบบมาตรฐาน รองรับกุญแจ ES256/attestation none และลงทะเบียนได้สูงสุด 10 รายการต่อบัญชี

`vendor/passkey-crypto.gs` ใช้ @noble/curves/@noble/hashes 2.4.0 และ @levischuck/tiny-cbor 0.3.6 ที่ bundle ไว้สำหรับ Apps Script V8 มีใบอนุญาตและ package integrity ใน vendor/ ไม่โหลดโค้ด crypto จาก CDN ขณะทำงาน
